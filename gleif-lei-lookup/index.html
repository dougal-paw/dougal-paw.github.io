LEI lookup API

Legal entity identifier data from the open GLEIF database, by LEI or company name.

Look up any legally-registered company's LEI record in one run. This Actor reads the official GLEIF API (api.gleif.org) for the LEIs or company names you give it, and returns one row per entity — registered legal name, status, legal form, jurisdiction, legal and headquarters addresses, registration dates, and optionally direct and ultimate parent companies.

Try it on Apify Store Free during launch

Why use it

  • Two lookup modes. Exact LEIs for direct lookups, company names for fuzzy legal-name search, or both in the same run.
  • Parent companies on request. With includeParents, each row also carries its direct parent and ultimate parent, when GLEIF has them on file.
  • Legal entities only. Sole-trader registrations (natural persons) are filtered out before they reach the output, so no personal data is returned.
  • Official, keyless, free. GLEIF's Golden Copy data is public domain (CC0).
  • Agent and pipeline friendly. Stable field names, a direct sourceUrl and an attribution field on every item.

How to call it from code

Run it synchronously and get the results straight back as JSON:

curl "https://api.apify.com/v2/acts/dougalpaw~gleif-lei-lookup/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "leis": ["5493001KJTIIGC8Y1R12"],
    "names": ["Apple Inc"],
    "includeParents": true
  }'
