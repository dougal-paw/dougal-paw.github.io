Bulk PageSpeed Insights checker

Core Web Vitals and Lighthouse scores for any list of URLs, mobile and desktop.

Run Google PageSpeed Insights against a list of URLs in one job. Give it any number of URLs and get back, per URL and per strategy (mobile/desktop), the Lighthouse scores (Performance, SEO, Accessibility, Best Practices), lab metrics (LCP, CLS, TBT, FCP, Speed Index), real-world Chrome UX Report field data, the top performance opportunities, and optionally the score delta against the last time you checked the same URL. No browser automation, no screenshots, no personal data.

Why use it

  • Bulk, not one-at-a-time. Check dozens of URLs, on mobile and/or desktop, in a single run instead of pasting URLs into the PageSpeed Insights website one by one.
  • Lab + field data together. Every result includes both the synthetic Lighthouse run and, when available, the real-user CrUX field percentiles and an overall field category.
  • Run-over-run tracking. Turn on compareWithPreviousRun to see how each score moved since the last check of that exact URL and strategy.
  • Works without an API key, with a free key supported for higher throughput.
  • Never crashes on one bad URL — a failed check gets a clear error field, not a failed run, and is never charged.

How to call it from code

Run it synchronously and get the results straight back as JSON:

curl "https://api.apify.com/v2/acts/dougalpaw~bulk-pagespeed-checker/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "urls": ["https://example.com", "https://www.wikipedia.org"],
    "strategies": ["mobile", "desktop"],
    "categories": ["performance", "seo"],
    "includeOpportunities": true
  }'

Data source and terms

Results come from Google's official PageSpeed Insights API v5, which combines Lighthouse (lab) and Chrome UX Report (field) data, subject to Google APIs Terms of Service. This Actor only sends the URLs you provide; it does not scrape or store third-party page content.

Google plans to stop including field data in the PageSpeed Insights API. If you supply your own Google API key with the Chrome UX Report API enabled, this Actor takes field data straight from the CrUX API and falls back to PSI otherwise. Doing it yourself? See our guide: moving from PSI field data to the CrUX API.
