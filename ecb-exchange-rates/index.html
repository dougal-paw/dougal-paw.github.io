ECB exchange rates API

Official European Central Bank euro reference rates, daily or monthly, keyless.

Get the European Central Bank's official euro foreign exchange reference rates in one call. This Actor reads the official ECB Data Portal SDMX API (data-api.ecb.europa.eu) and returns one row per date per currency pair — daily reference rates or monthly averages, in EUR terms or converted to any other base currency via EUR cross rates.

Try it on Apify Store Free during launch

Why use it

  • Official, keyless, free. Straight from the ECB's own SDMX statistical data warehouse, no API key, no HTML scraping.
  • Any base currency. Default output is EUR-based, exactly as the ECB publishes it. Ask for another base and the Actor computes the cross rate, marking the row derived: true.
  • Currency set stays current automatically — a currency that joins the euro area drops out of "all currencies" requests without needing a code update.
  • Correct weekday handling. No row is invented for weekends or TARGET holidays, when the ECB publishes no rate.
  • Agent and pipeline friendly. Stable field names, ISO dates, a sourceUrl straight to the underlying ECB series.

How to call it from code

Run it synchronously and get the results straight back as JSON:

curl "https://api.apify.com/v2/acts/dougalpaw~ecb-exchange-rates/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "currencies": ["USD", "JPY"],
    "baseCurrency": "USD",
    "startDate": "2026-11-09",
    "endDate": "2026-11-13"
  }'

Example output

{
  "date": "2026-11-13",
  "base": "EUR",

  "derived": false,
  "source": "ECB euro foreign exchange reference rates",

Data source and attribution

All data comes from the European Central Bank's official Data Portal SDMX API, the same source behind the ECB's published euro reference rates — free and keyless. The ECB states these rates are for information purposes only and strongly discourages their use for transaction purposes. Each item carries "source": "ECB euro foreign exchange reference rates" for attribution (Copyright © European Central Bank, Frankfurt am Main, Germany).
