USAspending contracts API

US federal contracts, grants and loans, searched and normalised to one schema.

This Actor queries the official USAspending.gov API — the US Treasury's public record of federal spending — for contracts, grants, loans, direct payments and other financial assistance, and returns each matching award as structured JSON: recipient, amount, dates, awarding agency, NAICS/PSC or CFDA classification, and location. Filter by keyword, award type, agency, NAICS, PSC, state, amount and date window.

Try it on Apify Store Free during launch

Why use it

  • One official source, one schema. Contracts, grants, loans, direct payments and other assistance all come back in the same normalised fields, even though USAspending models each differently internally.
  • Filters that matter for bid teams. Keywords, award type, awarding agency, NAICS and PSC codes, recipient/place-of-performance state, minimum amount, and a date window.
  • Official open API only. No browser, no HTML scraping, keyless, no proxies. The data is US-government public domain.
  • Organisations only. Output never includes a named individual recipient or any point-of-contact name, email or phone.
  • Agent and pipeline friendly. Stable field names, a direct awardUrl to the USAspending.gov award page, and an attribution field on every item.

How to call it from code

Run it synchronously and get the results straight back as JSON:

curl "https://api.apify.com/v2/acts/dougalpaw~us-federal-awards/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "keywords": ["cybersecurity"],
    "awardTypes": ["contracts"],
    "maxItems": 20
  }'
