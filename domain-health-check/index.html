Bulk SSL expiry and DNS checker

DNS, TLS certificate and HTTP/HTTPS health for any list of domains, in one run.

Give it any number of domains or URLs and get back, per domain, the DNS records (A/AAAA/MX/NS/TXT/CAA, SPF and DMARC presence), the live TLS certificate (issuer, expiry, hostname match, protocol), the HTTP → HTTPS redirect chain and HSTS header, plus a plain-English status (ok / warn / fail) and a list of human-readable issues. No WHOIS lookups and no personal data in the output.

Why use it

  • Three checks, one run. DNS, SSL/TLS and HTTP are checked for every domain and rolled up into a single ok/warn/fail status with plain-English issues like "SSL expires in 9 days" or "No DMARC record".
  • Real TLS handshake, not a cached API summary: issuer, validity window, days to expiry, SAN list, hostname match and negotiated TLS protocol version.
  • Redirect-chain aware. Every hop's URL and status is recorded, so you can see exactly whether and how HTTP gets upgraded to HTTPS, plus the HSTS header and response time.
  • Never crashes on a bad domain. A broken, expired or non-existent domain produces a fail item with a clear error message, not a failed run.
  • Privacy-safe by design. No WHOIS lookups; any email-like string in a DNS TXT record is redacted before it reaches the dataset.

How to call it from code

Run it synchronously and get the results straight back as JSON:

curl "https://api.apify.com/v2/acts/dougalpaw~domain-health-check/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "domains": ["example.com", "github.com", "expired.badssl.com"],
    "checks": ["dns", "ssl", "http"],
    "concurrency": 4,
    "timeoutSecs": 10,
    "sslExpiryWarnDays": 21
  }'

Data source

Checks use live DNS resolution, a real TLS handshake and a manual HTTP redirect trace against the domains you supply — no third-party WHOIS or certificate-transparency service. No personal data (such as WHOIS registrant details) is collected or output.

Who it's for

  • Agencies and freelancers auditing a client's domain portfolio before a migration or handover.
  • MSPs and IT teams checking many domains in one job instead of several separate tools.
  • SSL-expiry monitoring on an Apify schedule, alerting on any warn/fail status.
  • AI agents and automations that need a structured answer to "is this domain healthy?"
