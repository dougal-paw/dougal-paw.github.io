SEC EDGAR financials API

Normalised revenue, income, balance sheet and cash flow data, straight from SEC XBRL filings.

Get clean, normalised financial statement data for any US public company in one run. This Actor reads the official SEC EDGAR XBRL companyfacts API (data.sec.gov) for the tickers or CIKs you give it, and returns one row per company per fiscal period — revenue, net income, EPS, operating income, assets, liabilities, equity, cash and operating cash flow — in a single consistent schema, however each filer happened to tag its own statements.

Try it on Apify Store Free during launch

Why use it

  • One schema across filers. Companies tag the same concept (e.g. revenue) under different us-gaap XBRL tags; this Actor tries each known tag in order and maps the result onto one stable field name.
  • Correctly deduplicated periods. Each row is tied to one specific filing, so prior-year comparative figures never get mixed up with a period's own primary numbers.
  • Official, keyless, free. No browser, no scraping of filing text, no API key.
  • Agent and pipeline friendly. Stable field names, ISO dates, a direct sourceUrl to the filing's EDGAR index page, and an attribution field on every item.

How to call it from code

Run it synchronously and get the results straight back as JSON:

curl "https://api.apify.com/v2/acts/dougalpaw~sec-edgar-financials/run-sync-get-dataset-items?token=YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "tickers": ["AAPL", "MSFT"],
    "periodType": "annual",
    "lastNPeriods": 4
  }'

Data source and attribution

All data comes from the official SEC EDGAR XBRL Frames/Facts API, the EDGAR submissions index, and SEC's own company tickers list — free and keyless. As data from a work of the US federal government, EDGAR's filing data is public domain under 17 U.S.C. § 105. Requests identify themselves per SEC's fair access policy. Each item carries "attribution": "Source: SEC EDGAR (data.sec.gov), U.S. Securities and Exchange Commission". This Actor is not affiliated with or endorsed by the U.S. Securities and Exchange Commission.
